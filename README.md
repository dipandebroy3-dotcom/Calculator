# Calculator Website

A simple and responsive calculator built using **HTML, CSS, and JavaScript**. This is my **first web development project**, created to strengthen my understanding of front-end development, DOM manipulation, event handling, and JavaScript logic.

## Features

* Basic arithmetic operations (+, −, ×, ÷)
* Clear (AC) functionality
* Responsive design for desktop and mobile devices
* Clean and user-friendly interface

This project marks the beginning of my web development journey, and I look forward to building more advanced projects while continuously improving my skills.

**Tech Stack:** HTML5, CSS3, JavaScript
